# CRM（顧客管理ページ）リニューアル 設計メモ

作成: 2026-09-13　状態: **ルール設計中**（まだ実装していない）

目的: 「どのお客さんに何をやればいいか」が一目で分かる顧客管理にする。
今のカンバン（列で扱いを表す方式）は、列を増やしても判断が楽にならなかった。

## 骨格（優秀なCRMの型を採用）

1. **工程と扱いを分ける** — 列は「お客さんが今どの工程にいるか」だけ。どう扱うかは機械が計算する
2. **次のアクティビティが必ず入っている** — 次回接触日が空の人をゼロにする
3. **ケイデンス** — 反響から「直後→平日→土日」のように決めた順で連絡する
4. **腐り検知** — 一定日数動きがないと赤くする
5. **やることは3箱** — 期限切れ／今日／これから

### 工程（列）は6つに減らす

```
反響 → 追客中 → 内見 → 申込 → 成約 ／ 失注
```
- 「時期待ち」は列ではなく保留フラグ（期限が近づいたら自動で戻る）
- 「未反応」「条件確定」「条件調整中」は列を廃止し、表示上の印にする

### 画面（案3: 2画面）

左に「やること」（期限切れ／今日／これから）、右にその人の詳細と1タップ操作。
今のカンバンは残し、別URLで並行して使う。落ち着いたら入口を切り替える。

## 顧客の種類と扱い（ユーザー案・2026-09-13）

### ① 未接続（LINEに来ていない）

| 種類 | 扱い | 抜け方 |
|---|---|---|
| メールだけ | 自動メール（今のフォローアップ）。人は触らない | LINEに来たら② ／ 一定期間来なければ失注 |
| 電話もある | 架電3回（早めに1回・平日1回・土日1回）。メールも並行 | LINEに来たら② ／ 3回つながらなければ失注 |

### ② LINEに来た

| 種類 | 扱い |
|---|---|
| 登録だけ | 条件登録の案内を1回リマインド。動きなしなら静かに置く（失注にしない） |
| 空室確認だけ | 結果を返したあと条件登録へ誘導。反応なしならリマインド1回 |
| 条件登録済み | → ③ |

### ③ 条件登録済み

| 種類 | 判定 | 扱い |
|---|---|---|
| 優先 | 連絡がつく（直近の受信・通話あり）または 引越し期限が近い | 人が毎日見る。やることに出る |
| 通常 | それ以外 | 自動に任せる。強い合図が出たときだけ人が動く |

## 決まったルール

- **A 反響**: 営業時間内は1時間以内、時間外は翌営業日午前に架電。つながらなければ 直後→平日→土日 の3回。3回ダメで LINEあり→追客中、LINEなし→失注
- **B 送付後の合図**: 電話するのは強い合図のときだけ
  - 申込／内見の画面を開いて送らなかった → 当日中に電話
  - 同じ物件を3回以上、または3件以上開いた → 当日中に電話（ダメならLINE）
  - 1件見ただけ → 何もしない（印だけ）
  - 開いていない → 翌日に1回だけひと言。それ以上追わない
- **C LINE受信**: 受信は自動で記録できる（webhook）。返信済みかは自動では分からない → 既存の✓完了で消す。こちらから送った分の追いはルールにしない（送るときに次回接触日を入れるかで決める）
- **D 送れる物件がない**: 7日で近況ひと言、14日で条件を広げる提案
- **E 引越し期限**: 60日前で間隔を半分、30日前で毎日、14日前は時期確認のみ（返事なしで保留か失注）
- **F 温度感**: 間隔は変えない。記録だけ（なくてもよい）
- **G 1タップ記録**: 📞話せた／📵つながらず／📨LINEした／👀内見（予定・結果）／✋失注（理由）。どれもそのあと次回接触日を選ぶ
- **H 内見**: 内見希望ボタンは合図であって記録ではない。担当者が予定（日付・物件）→結果（申込／見送り／流れた）を入れる。前日に確認連絡、翌日に結果を聞く、がやることに出る

## 取る材料（追加）

1. お客様からのLINE受信日時 — 自動（webhookで来ている）
2. 次回接触日 — Gのタップ時に必ず入れる
3. 内見の予定と結果 — 担当者が入力
4. 失注理由 — ✋のとき選ぶ
5. 温度感 — 任意
- 架電可能時間帯は取らない（ほとんどつながらないため）

## まだ決めていない数字

1. ①メールだけ: LINEに来なければ失注にするまで何日
2. ②登録だけ／空室確認だけ: リマインドは何日後（案: 3日）
3. ③優先の判定: 直近何日以内の受信・通話（案: 14日）／引越しまで何日以内（案: 60日）
4. ③通常で自動提案が出尽くしたあと（今は10日×3回）: 保留にして寝かせるか
5. 自動提案の頻度と期間の見直し（案1: 7→14→21日で3回、反応なしで保留）
6. 失注理由の選択肢（案: 他社で決めた／条件が合わない／連絡つかず／時期延期／予算／その他）

## 進め方

1. 「対応ルール」シートを作り、閾値をそこに置く（コードに埋めない）
2. 材料の追加（LINE受信日時・次回接触日・内見・失注理由）
3. まず今のカンバンのカードに「次の一手」を出す
4. 2画面ページを別URLで作り、並行運用
5. 落ち着いたら入口を切り替える

- 1日1回の✓完了: `CustomerPage.html` `DAILY_CHECK_STAGES` / `checkedToday`
