#### LINE登録メールについて

`LINE登録メール` シート（メール / userId / 表示名 / 登録日時）はLINE APIから取得したものではない。
**お客様が友だち追加後に「メール配信を止めたい」流れで自分でメールを打った時だけ**記録される（`コード.js:326`）。したがって**確実に紐づくのは一部の人だけ**。

#### 統合時の引き継ぎ

統合の既定ルールは「**残す側が空のときだけ埋める**」なので、本名（問い合わせ側）に値があると常にそちらが勝つ。ステータスとステージだけこれと相性が悪いため選択欄を用意した。

```
統合先の名前（残す方）    ◉ 小山恵李      ○ こやまえり
配信ステータス（残す方）  ○ lead         ◉ （なし＝配信中）(LINE側)
営業ステージ（残す方）    ○ 問い合わせ    ◉ （空欄→追客中）(LINE側)
```

**LINE紐付けのある側が既定**。LINE側が `paused`/`blocked` ならその停止が維持される（意図的な停止を勝手に解除しない）。
